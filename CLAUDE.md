## Project status

This repo is being repurposed for a **habit-tracker app with a virtual pet** (Flutter, Android first). The app has not been scaffolded yet. [PLAN.md](PLAN.md) (in Vietnamese) holds the product design, the mechanics borrowed from Habitica, the tech stack and the phased roadmap. Read it before starting any work, and follow its phase order.

The previous project, a Godot monster-tamer game, is preserved on the `archive/ngu-thu-game` branch. Its pet sprites may only be reused once their source and license are confirmed.

- Once the Flutter project exists, replace this section with the real build, test and run commands and an architecture overview.
